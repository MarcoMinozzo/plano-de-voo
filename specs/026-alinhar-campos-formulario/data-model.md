# Data Model: Alinhar campos do formulário

This feature does not add or change data entities, persistence, or server-side form fields.

The existing form inputs remain unchanged:

- `hora_partida`: date and time.
- `numero_passageiros`: passenger count.
- `peso_pessoas_kg`: people weight in kilograms.
- `peso_bagagem_kg`: baggage weight in kilograms.

Only their visual grouping changes.
