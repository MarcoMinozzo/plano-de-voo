# Fontes iniciais para pesquisa de dados didáticos

Estas fontes foram indicadas pelo usuário como pontos de partida. A inclusão
nesta lista não confirma a cobertura do modelo/variante nem torna os valores
verificados.

| Fonte | Uso esperado | URL |
|---|---|---|
| AOPA Aircraft Fact Sheets | Especificações e características de aeronaves | https://www.aopa.org/go-fly/aircraft-and-ownership/aircraft-fact-sheets |
| Pilot-Next | Comparações de consumo de combustível entre modelos | https://pilot-next.com/blog/how-much-fuel-does-a-cessna-172-burn |
| Aeroway | Calculadora com consumo, combustível, capacidade e autonomia | https://www.aeroway.org/calculators/aircraft-fuel-burn-calculator/ |
| FAA | Regulamentos e documentação aeronáutica oficial | https://www.faa.gov/ |

Para cada valor usado, registrar a unidade, fonte direta, data, modelo/variante
e perfil a que se aplica. Não tratar uma calculadora genérica ou uma comparação
sem variante explícita como dado confirmado.
